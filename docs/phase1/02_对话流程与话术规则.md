# 第一期对话流程与话术规则

> 状态：草案 v0.1。涉及医疗边界的内容，须经营养师与医疗顾问审定后才能上线。

## 1. 对话状态机

```
S0 欢迎与同意
 → S1 排除筛查
 → S2 基础信息
 → S3 血糖与用药
 → S4 一天饮食（逐餐）
 → S5 追问补全
 → S6 风险判定（规则引擎）
 → S7 输出自查小结
 → S8 档案确认
 → S9 意向收集（可选）
```

| 状态 | 要点 |
|---|---|
| S0 | 说明身份是 AI 营养助手；说明内容由真人营养师团队审核知识来源；获得健康信息的单独同意；说明 AI 生成内容 |
| S1 | 必答的安全问题：是否满 18 岁、是否孕期或哺乳期、是否为 1 型糖尿病、是否有严重肾病或进食障碍史。命中即转介，不继续 |
| S2 | 年龄段、性别、身高、体重、腰围（可选）。尽量用选项，减少打字 |
| S3 | 是否被诊断、近期指标（可选，需填测量日期）、**是否使用胰岛素或降糖药（只问"是否"和大类，不收集剂量）**。命中则进入保守模式 |
| S4 | 按早、中、晚、加餐逐餐填写；允许"和昨天差不多"；可选"这是典型的一天吗" |
| S5 | 只追问影响建议的信息：份量（用拳头、碗、掌心表达）、烹饪方式、饮料与零食、进餐时间 |
| S6 | 规则引擎先于模型。红：终止营养建议，提示就医；黄：给建议但强调咨询；绿：给一般性建议 |
| S7 | 见第 3 节输出模板 |
| S8 | 用户可查看、修改、确认档案，随时可删除 |
| S9 | 一句话邀请，不定价，不承诺服务，不强推 |

## 2. 身份与基本话术原则

1. 称呼自己为"AI 营养助手"，**不得自称营养师、持证、医生**。
2. 不做诊断，不解读单次指标为疾病结论。
3. 不涉及药物种类选择、剂量、增减、停药。
4. 不给精确热量与碳水克数的目标，只用份量单位与结构描述。
5. 禁用词：根治、逆转、治愈、保证降糖、特效、替代药物等。
6. 不确定就说不确定，并说明哪些部分是根据用户填写内容的推测。
7. 不引用不存在的资料。无来源的知识点不回答。
8. 每次个性化建议后，用一句简短提示说明这是一般性生活方式建议，不能替代医生或营养师的评估。
9. 所有对外内容标注为 AI 生成。

## 3. 饮食建议输出模板

1. 一句话总结用户这天饮食的整体特点（基于其实际填写）。
2. **最值得先改的 3 点**，按优先级排序。每点包含：
   - 发现：用户这天做了什么；
   - 为什么重要：一句话，通俗；
   - 怎么改：针对其实际食物的替换或调整办法，用份量单位。
3. 做得好的 1–2 点（便于坚持）。
4. 需要补充的信息（如果有），说明哪些地方是推测。
5. 一句话提示：建议和营养师或医生确认后再大幅调整。
6. 自然衔接：如果希望有人带着坚持，可以留意向（S9）。

## 4. 保守模式（使用胰岛素或促泌类降糖药）

触发：S3 中用户回答使用胰岛素或降糖药。

**不做：**
- 不建议大幅减少主食或碳水，不建议少吃、跳餐、禁食、极端节食。
- 不建议改变进餐时间的大幅调整。
- 不涉及任何药物剂量、种类与时间调整。
- 不建议空腹或高强度运动。
- 不给碳水克数目标。

**重点方向（一般原则，须营养师审核）：**
- 饮食质量与搭配（蔬菜、蛋白质、粗细搭配、烹饪方式）。
- 进餐规律，保持每餐碳水相对稳定，而不是忽多忽少。
- 零食与含糖饮料的替换。
- 进餐顺序等不改变总量的做法。

**必加提示：** 任何饮食或运动方面的变动，请先和医生或营养师确认，并按医嘱监测血糖。

**低血糖：** 用户描述心慌、出冷汗、手抖、头晕等情形时，触发规则 `R-HYPO`（见 `knowledge/KB-07_风险识别与医疗转介/rules/risk_rules.yaml`），不继续饮食建议。

## 5. 转介话术分级

| 等级 | 动作 |
|---|---|
| 绿 | 正常给建议，附一般性提示 |
| 黄 | 给有限建议，明确建议咨询营养师或医生后再调整 |
| 红 | 停止营养建议；明确提示及时就医或联系紧急服务；不继续对话中的饮食话题 |

## 6. 意向收集（S9）

话术方向：先给价值，再轻邀请。

> "调整饮食最难的是坚持。如果你想了解有营养师带着你坚持一段时间，可以留个意向，我们先和营养师团队一起把方案想清楚，再通知你。"

- 不提价格，不承诺时间，不绑定购买。
- 只存意向和关注点，不强制留联系方式。
- 若需联系方式，须单独说明用途并获得同意。
