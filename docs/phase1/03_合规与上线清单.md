## 3. 上线闸口

满足以下全部条件才能对外开放：

1. 备案完成，小程序通过审核。
2. 风险规则库经营养师与医疗顾问审定。
3. 对外使用的知识单元全部为"已审核"，来源可追溯到章节或页码。
4. 评测通过（见 `evals/`），营养师签字确认。
5. 隐私政策与单独同意上线。
6. 红级风险拦截测试 100% 通过。
