# 知识单元模板（SeekNutri 标准版）

| 字段 | 内容 |
|------|------|
| **知识编号** | KBXX-XXX（示例：KB00-001） |
| **知识主题** | 简短、明确的主题名称 |
| **核心知识** | 经过提炼、准确、可直接使用的知识点（禁止简单复制原文） |
| **适用人群** | 明确适用对象（如：健康成人 / 超重人群 / 糖尿病前期等） |
| **使用场景** | 用户在什么情况下会问到这个问题 |
| **适用限制** | 哪些情况不能直接套用本知识 |
| **证据来源** | 原始资料完整名称 + 发布机构 + 版本/日期 + 对应章节或页码 |
| **证据等级** | 高 / 中 / 低（或标注为专家共识、指南推荐、研究证据等） |
| **AI追问** | 回答前还需要向用户确认的关键信息（用于动态追问） |
| **风险提示** | 哪些情况必须提示就医、转交营养师或停止自行调整 |
| **适用端** | 用户端 / 营养师端 / 两端共用 |
| **用户端输出深度** | 简洁版 / 标准版 |
| **营养师端输出深度** | 标准版 / 详细版（含证据与参考文献） |
| **权限等级** | 公开 / 仅营养师 / 仅内部 |
| **渠道适配建议** | 通用 / 小红书倾向 / 微信倾向 / 抖音倾向（默认选通用） |
| **审核状态** | 待审核 / 已审核 / 待核实 / 已撤回 |
| **最后更新** | YYYY-MM-DD |
| **审核人** |  |
| **版本号** | v1.0 |
| **备注** | 其他需要说明的内容 |
