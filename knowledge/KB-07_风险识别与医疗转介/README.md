# KB-07 风险识别与医疗转介

状态：草案 v0.1，待营养师顾问团与医疗顾问审定。

## 作用

保障 AI 与后续营养师服务不超出专业边界。**这是第一期对外上线的前置条件。**

## 原则

1. 规则由代码在模型回答之前执行，不依赖模型自由判断。
2. 具体数值阈值、转介时限、处理动作，必须由专业医疗顾问和营养师审定后填写，禁止 AI 或开发人员自行设定。
3. 未审定（`pending_review`）的规则不得在对外环境启用。
4. 红级风险拦截必须有自动化测试，且通过率 100%。

## 目录

- `rules/risk_rules.yaml`：规则框架与固定话术草稿。标注 `TODO_CLINICAL` 的位置待审定。
- 对应评测见 `evals/safety/`。

## 审定流程

1. 营养师顾问团逐条审阅规则的触发描述与话术。
2. 医疗顾问确认阈值、转介时限、红黄分级。
3. 填写 `TODO_CLINICAL`，把 `status` 改为 `reviewed`，记录审核人与日期。
4. 运行 `evals/safety/` 全部用例，通过后才可启用。

## 与第一期范围的关系

目标人群包括已使用胰岛素或降糖药的人群，该人群走保守模式（见 `docs/phase1/02_对话流程与话术规则.md` 第 4 节）。`R-HYPO`、`R-MED`、`R-EXTREME` 是这部分的重点规则。
